# Test fixtures

Every file here is synthetic, made for tests only. None is a real medical record.

- `report.pdf`: a sample report with invented content.
- `xray.png`: a generated image, not a real scan.

Rules for new fixtures:
- Generate them with code or make them by hand, with invented content.
- Mark them "SAMPLE - NOT A REAL RECORD" where the format allows.
- Never add a real report, prescription, scan or photo, even redacted or blurred.
- Keep them small (under 1 MB) so the repository stays light.
